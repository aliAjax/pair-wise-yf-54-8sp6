# pair-wise-yf-54 博物馆展品点交与核验账

## 源提示词摘要
策展人、保管员、布展负责人和借展方从到场点交、环境条件检查、安装位置确认到闭展归还共同处理展品。系统记录条件、附件、风险等级、照片说明、处理意见和签字结果，差异项未解决时不能进入下一阶段，并支持大量展品与断网暂存。

## 本次新增：离线平板回传核验账
几块离线平板导出交接文本后，另一台核验设备按**操作编号**去重合并字段，解决"后到数据覆盖先到数据"的问题。

- **交接文本导入**：平板导出 `[操作编号] 类型 展品编号 / 键 = 值` 文本，核验设备粘贴导入。
- **按操作编号去重**：已入账操作直接跳过，不重复执行。
- **字段级合并 + 两版并列**：同字段出现不同值时保留两版（及来源平板/操作编号），选定版本后才能推进；新版与已选定版本冲突时自动重开。
- **结论失效退回待复核**：已确认结论的展品，读数或差异项一旦变化，结论立即失效、展品退回待复核，需重新确认。
- **失败只重试未入账**：导入失败的操作落 `failed`，重试只跑未入账操作，已入账操作不重跑。
- **柜位容量排队**：柜位满时展品排队候位，腾出容量后可补入。
- **越权确认直接拒绝**：所有确认/推进/调整动作按角色校验，无权操作直接拒绝并提示。
- **保管员只处理本柜冲突**：保管员仅能处理本柜（A2）展品的冲突与差异，他柜操作一律拒绝。

## 技术栈
Vue 3 + TypeScript + Vite + Vuetify + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 展品、环境检查、差异项三类业务对象（原有点交标签页）。
- 到场点交、布展核验、闭展归还的分阶段签字与推进门禁。
- 未解决差异阻断流转，可单独确认解决。
- `v-virtual-scroll` 大列表、离线队列提示、手动确认同步。
- **核验账标签页**：交接文本导入、字段冲突两版并列选定、结论失效待复核、失败重试、柜位排队补入、四类角色权限。
- localStorage 持久化。

## 交接文本格式
```
# 博物馆点交交接文本 v1
# 来源平板：tablet-B
# 导出时间：2026-10-04T09:30:00Z

[OP-B1] exhibit M001
  年代 = 周

[OP-B3] discrepancy M003
  标题 = 封条开裂
  严重 = major
```
类型：`exhibit` / `reading` / `discrepancy` / `cabinet`。
